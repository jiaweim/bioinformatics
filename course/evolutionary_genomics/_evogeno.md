# 进化基因组学与生物信息学



## 简介

这是由 Jeffrey Blanchard 教授在马萨诸塞大学阿默斯特分校讲授的“进化基因组学与生物信息学”课程资料库中 HTML 文件的渲染页面。

## 同步仓库

按照以下说明创建一个与课程 GitHub 仓库同步的 RStudio 项目空间，并下载仓库中的文件。

1. 访问 https://github.com/jeffreyblanchard/EvoGeno2024R
2. 点击绿色的 "Code" 按钮，并复制 https 链接 (`https://github.com/jeffreyblanchard/EvoGeno2024R.git`)
3. 在 RStudio 中，点击 **File > New Project**（您无法在 RStudio Cloud 上执行此操作，只能在 Unity 或您自己电脑上安装的 RStudio 中进行）
4. 选择 **Version Control**（版本控制）
5. 选择 **Git**
6. 粘贴从课程 GitHub 网站复制的链接 (`https://github.com/jeffreyblanchard/EvoGeno2024R.git`)
7. 选择您希望用于该项目的目录（通常是 `/project/username`）
8. 在右上角选择 **git** 标签页。当您想更新文件时，请点击 **pull**（拉取）。
